# Nemo's Dev Portfolio

A personal portfolio website featuring my projects, skills, and a live weather dashboard for Detroit, Michigan.

## How to Run

1. Clone or download this repository
2. Open the project folder in VS Code
3. Install the Live Server extension if you don't have it
4. Right-click `index.html` and select **Open with Live Server**
5. Navigate to the Weather Dashboard via the portfolio navbar

## Weather Dashboard

Located at `api-index.html`, the dashboard pulls live weather data from the Open-Meteo API.

- **Weekly Forecast** — 7-day temperature forecast with daily highs and lows
- **Current Conditions** — wind speed, precipitation, cloud coverage, and humidity

## API Used

- [Open-Meteo](https://open-meteo.com/) — free, no API key required
